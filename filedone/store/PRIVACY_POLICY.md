# FileDone Privacy Policy

Effective date: 2026-10-02
Applies to the current Microsoft Store version of FileDone.

FileDone is a Windows file-processing utility. The current version processes user-selected files locally on the Windows device.

## Data accessed
When a FileDone action is invoked from File Explorer, FileDone reads the selected file or files and the file information needed to perform that operation.

## Local operation history
FileDone stores a local operation history at %LOCALAPPDATA%\FileDone\logs\runtime.jsonl.
The current log can contain timestamps, selected action, input file paths, output path, operation status, and diagnostic detail. File paths can contain user-chosen names and should be treated as local personal data.

## Network transmission and telemetry
The current shipping version contains no FileDone feature that uploads selected files, sends this local operation history to FileDone, requires a FileDone account, or sends FileDone analytics or telemetry. File processing uses bundled components and Windows media facilities on the local device.

## Outputs and Safe to Share
FileDone creates new output files rather than intentionally replacing the selected source file.
Safe to Share removes removable media metadata from the generated copy. It does not guarantee removal of identifying information that is visibly or audibly embedded in the content itself.

## Retention and deletion
Output files and the local history remain on the user's device until deleted by the user or by a future product maintenance function. FileDone does not operate a FileDone cloud service for this data in the current version.

## Future changes
If a future release adds accounts, cloud processing, telemetry, network services, or changes local data storage, this policy must be updated before that release is submitted.
