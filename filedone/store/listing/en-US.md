# FileDone — Microsoft Store listing (en-US)

## Name
FileDone

## Short description
Handle common file tasks directly from Windows File Explorer: convert for compatibility, reduce file size, fit media under a target size, remove removable media metadata, or combine images into a PDF.

## Description
FileDone puts everyday file operations in the Windows 11 File Explorer context menu, so routine conversions do not require opening a large editor.

Make Compatible converts supported images, videos, and audio to common formats.
Make Smaller compresses supported media to reduce file size.
Fit Under... accepts a target size in MB and attempts to keep supported images or videos at or below that limit.
Safe to Share creates a copy with removable metadata stripped; video and audio metadata and chapters are removed.
Make PDF combines selected images into a single PDF in selection order.

The current version processes files locally, requires no FileDone account, and contains no FileDone upload or telemetry path. Outputs use new filenames instead of directly overwriting the selected source.

## Product features
Windows 11 File Explorer context-menu integration
Common image, video, and audio compatibility conversion
One-click media size reduction
Target-size compression for images and videos
Removal of removable media metadata
Multi-image PDF creation
Local processing with no FileDone account required
