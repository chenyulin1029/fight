# FileDone — Microsoft Store listing (zh-TW)

## 名稱
FileDone

## 短描述
直接從 Windows 檔案總管完成常用檔案整理：轉成相容格式、縮小容量、壓到指定大小、移除可移除的媒體中繼資料，或把多張圖片合成 PDF。

## 完整描述
FileDone 把日常檔案處理放進 Windows 11 檔案總管右鍵選單，不需要先開啟大型編輯軟體。

五個動作：
Make Compatible：將支援的圖片、影片或音訊轉成較常見的相容格式。
Make Smaller：壓縮支援的媒體以降低檔案容量。
Fit Under...：輸入目標 MB，讓支援的圖片或影片嘗試壓到指定容量以下。
Safe to Share：建立移除可移除中繼資料的副本；圖片移除可移除 metadata，影片與音訊移除 metadata 與 chapters。
Make PDF：多選圖片後，依選取順序建立一份 PDF。

目前版本在本機處理檔案，不需要 FileDone 帳號，也沒有 FileDone 主動上傳檔案或遙測的程式路徑。輸出以新檔名建立，不直接覆寫來源檔。

## 產品功能
Windows 11 檔案總管右鍵整合
常見圖片／影片／音訊相容格式轉換
一鍵縮小媒體檔案
圖片／影片指定 MB 上限
移除可移除的媒體中繼資料
多張圖片建立單一 PDF
本機處理，不需 FileDone 帳號
