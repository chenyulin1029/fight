# FileDone Privacy Policy — Store Draft

Last updated: 2026-10-02

FileDone is a Windows file-processing utility that adds file actions to Windows File Explorer.

## Data FileDone accesses

FileDone accesses files only when the user selects files and invokes a FileDone action. Depending on the selected action, FileDone reads the selected local file and writes a processed output file on the user's device.

The current Store Release Candidate does not include an account system, advertising SDK, analytics SDK, telemetry service, cloud-processing service, or network-upload feature.

## Local processing

File conversion and processing are performed on the user's Windows device using the components shipped with FileDone. User-selected file contents are not transmitted by FileDone to FileDone-operated servers or third-party processing services.

## Local history log

FileDone maintains a local runtime history log for operational diagnostics. The log may include:
- UTC timestamp
- action name
- local input file path(s)
- local output file path
- success/failure status
- diagnostic detail

The log is stored locally at:

%LOCALAPPDATA%\FileDone\logs\runtime.jsonl

FileDone does not transmit this log. The user may delete this file locally.

## Third parties

FileDone does not sell user data and does not send user-selected file contents or the local runtime history log to advertisers or analytics providers.

## Security

FileDone processes user-selected files locally. Users should keep Windows and FileDone updated and should only process files they trust.

## Changes

If future FileDone versions add network services, accounts, telemetry, cloud processing, or other data practices, this privacy policy must be updated before those features are released.
